GitHub Gmail Finder

Search GitHub users by area, and collect the Gmail addresses they list publicly on their profiles.

Connect your GitHub token

This app needs a GitHub personal access token to search GitHub. It is saved only on this computer, in the project's .env file.

  1. Open GitHub → New fine-grained token (log in if asked).
  2. Enter any name, choose an expiration, and select Public repositories (read-only). No extra permissions are needed.
  3. Click Generate token, copy it, and paste it below.
